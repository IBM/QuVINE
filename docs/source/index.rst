#######################################
QuVINE
#######################################

QuVINE is an open-source framework for quantum and classical view-based network
embedding workflows. It combines graph preparation, graph complexity analysis,
quantum and classical random-walk methods, embedding generation, fusion, and
downstream evaluation for network biology and related graph-learning settings.

QuVINE is designed to support both method development and applied analysis,
with reusable APIs, experiment pipelines, and structured documentation.

----------------------------------------------------------

Key Features
========================

* **Graph complexity analysis**: spectral, centrality, quantum-inspired, and QBC-style complexity metrics.
* **Quantum and classical walk pipelines**: RWR, CTQW, DTQW, and hybrid workflow support.
* **Embedding workflows**: view generation, embedding training, calibrated filters, and fusion.
* **Evaluation support**: ranking, classification, and link prediction utilities.
* **Research-ready structure**: configs, scripts, examples, notebooks, and test coverage.
