QuVINE Documentation
====================

QuVINE is a framework for quantum and classical network embedding workflows,
including graph preparation, complexity analysis, walk generation, embedding,
fusion, and downstream evaluation.

This Sphinx-style documentation index is designed to work with autodoc-based
API documentation and the existing narrative guides already present in the
repository.
